# Assets institucionais da UHMR

Este diretório será a fonte local dos elementos visuais utilizados pela apresentação UHMR.

## Regra

A apresentação não deve depender de assets hospedados em outro repositório, inclusive CIATOX.

## Assets a incorporar

- `governo-ses-mt.png`
- `logo-cievs-mt.png`
- demais marcas oficialmente aprovadas para a UHMR

## Procedimento

1. obter arquivo oficial/aprovado;
2. registrar origem institucional;
3. preservar proporção;
4. adicionar ao repositório UHMR;
5. atualizar HTML para caminho relativo;
6. validar desktop, mobile e impressão/PDF;
7. remover a referência externa somente depois de confirmar que o asset local está disponível.

## Situação atual

A migração dos binários permanece pendente nesta branch para evitar quebrar a apresentação antes que as cópias locais sejam incorporadas.
