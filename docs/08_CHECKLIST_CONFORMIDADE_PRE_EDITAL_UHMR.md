# SES-MT - UHMR
## Checklist de Conformidade Pré-Edital

**Código:** UHMR-GOV-002  
**Versão:** 2.0 - minuta  
**Uso:** gate de liberação para submissão às instâncias formais.

## A. Governança

- [ ] equipe de planejamento formalmente designada;
- [ ] unidade demandante identificada;
- [ ] PCA/planejamento compatibilizado;
- [ ] processo administrativo corretamente instruído;
- [ ] responsabilidades definidas.

## B. DFD e ETP

- [ ] problema público claramente descrito;
- [ ] necessidade separada da solução;
- [ ] alternativas avaliadas;
- [ ] solução escolhida justificada técnica e economicamente;
- [ ] quantitativos possuem memória de cálculo;
- [ ] dados utilizados possuem fonte e data;
- [ ] levantamento de mercado concluído;
- [ ] parcelamento avaliado;
- [ ] resultados pretendidos definidos;
- [ ] riscos mapeados;
- [ ] conclusão de viabilidade expressa.

## C. Base legal

- [ ] Lei nº 14.133/2021 verificada;
- [ ] Decreto MT nº 1.525/2022 verificado;
- [ ] alterações estaduais supervenientes verificadas;
- [ ] instruções SEPLAG vigentes verificadas;
- [ ] orientações/PGE aplicáveis verificadas;
- [ ] normas sanitárias verificadas;
- [ ] normas trabalhistas verificadas;
- [ ] legislação de incêndio verificada;
- [ ] exigências ambientais verificadas;
- [ ] normas técnicas validadas pela engenharia.

## D. Termo de Referência

- [ ] objeto preciso e neutro;
- [ ] escopo e não escopo;
- [ ] níveis N0-N4 descritos;
- [ ] requisitos possuem IDs;
- [ ] critérios de aceite;
- [ ] SLA mensuráveis;
- [ ] responsabilidades;
- [ ] mobilização;
- [ ] implantação;
- [ ] operação;
- [ ] manutenção;
- [ ] consumíveis;
- [ ] expansão/redução;
- [ ] desmobilização;
- [ ] recomposição de prontidão;
- [ ] medição;
- [ ] pagamento;
- [ ] gestão e fiscalização;
- [ ] proteção de dados;
- [ ] propriedade/portabilidade de dados;
- [ ] continuidade.

## E. Competitividade

- [ ] ausência de marca sem justificativa legal/técnica;
- [ ] requisitos restritivos individualmente justificados;
- [ ] capacidade técnica proporcional;
- [ ] experiência exigida relacionada às parcelas relevantes;
- [ ] exigências econômico-financeiras justificadas;
- [ ] prazos confrontados com o mercado;
- [ ] prova de conceito/testes com regras objetivas.

## F. Pesquisa de preços

- [ ] metodologia documentada;
- [ ] fontes registradas;
- [ ] premissas comparáveis;
- [ ] custos segregados;
- [ ] custo de prontidão separado da ativação;
- [ ] custo total de propriedade analisado;
- [ ] data-base definida;
- [ ] orçamento máximo tratado conforme regras vigentes.

## G. Engenharia e sanitário

- [ ] layout funcional validado;
- [ ] fluxos avaliados;
- [ ] energia e redundância;
- [ ] gases medicinais;
- [ ] água/WASH;
- [ ] climatização;
- [ ] resíduos;
- [ ] incêndio;
- [ ] acessibilidade;
- [ ] autorizações/licenças;
- [ ] responsável técnico;
- [ ] comissionamento.

## H. Contrato

- [ ] obrigações coerentes com o TR;
- [ ] matriz de responsabilidades;
- [ ] matriz de riscos quando cabível;
- [ ] garantias;
- [ ] seguros;
- [ ] reajuste;
- [ ] revisão;
- [ ] sanções;
- [ ] hipóteses de suspensão;
- [ ] encerramento;
- [ ] recebimento;
- [ ] transição/desmobilização.

## I. PGE e fluxo estadual

- [ ] prazo interno considera a antecedência exigida para análise jurídica quando aplicável;
- [ ] manifestação técnica acompanha questões normativas;
- [ ] documentos estão consistentes antes do envio jurídico;
- [ ] pendências estão explicitamente listadas.

## J. Publicação

- [ ] dados pessoais removidos;
- [ ] documentos públicos sem informação restrita;
- [ ] links válidos;
- [ ] versão correta;
- [ ] aprovações registradas;
- [ ] artefatos finais correspondem às fontes versionadas.
